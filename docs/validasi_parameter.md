# Batas ilmiah model

Data BPS adalah data curah hujan bulanan, bukan kelembapan tanah atau kebutuhan air tanaman. Model trapesium, batas 60–180 dan 450 mm, eksponen kerentanan, indeks 0–100, ukuran piksel, dan umur fase belum dikalibrasi. Kategori simulasi bukan mutu komersial. Stres kering dan basah dipisahkan secara heuristik. Genangan adalah ilustrasi, bukan hasil model drainase. Jumlah daun dewasa 24 dan vegetatif 16 adalah pilihan visual sementara; perlu pengukuran lokal berdasarkan fase dan varietas.
